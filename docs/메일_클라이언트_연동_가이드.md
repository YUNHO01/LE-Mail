# 📧 LEMail 외부 메일 클라이언트 연동 가이드 (Outlook / Thunderbird 등)

본 문서는 **Microsoft Outlook**, **Mozilla Thunderbird**, **Apple Mail** 등 외부 메일 클라이언트 프로그램에서 **IMAP / SMTP** 프로토콜을 통해 LEMail 계정을 연동하고 사용하는 방법을 안내합니다.

> [!NOTE]
> 별도의 클라이언트 프로그램 설치 없이 웹 브라우저나 스마트폰 홈 화면 앱으로 이용하시려면 데스크톱 웹메일(`https://mail.yourdomain.com`) 또는 모바일 PWA(`https://m.yourdomain.com`)를 이용하십시오.

---

## 1. 공통 서버 설정 정보

운영 환경(방화벽 및 포트 포워딩/Nginx 프록시 적용 기준)의 기본 접속 정보는 아래와 같습니다.

| 구분 | 항목 | 권장 설정값 | 내부 직결 포트 (참고) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **계정 정보** | **이메일(사용자 이름)** | `user@yourdomain.com` | - | 아이디만 입력하지 말고 `@도메인` 포함 전체 주소 입력 |
| | **비밀번호** | LEMail 로그인 비밀번호 | - | |
| **받는 메일 (IMAP)** | **서버 주소** | `mail.yourdomain.com` | - | 메일 서버 공인 도메인 |
| | **포트 / 암호화** | **`993`** / **`SSL/TLS`** *(권장)* | `1993` | Direct TLS 암호화 |
| | *(대체 설정)* | **`143`** / **`STARTTLS`** | `1143` | 평문 연결 후 TLS 업그레이드 |
| **보내는 메일 (SMTP)** | **서버 주소** | `mail.yourdomain.com` | - | |
| | **포트 / 암호화** | **`25`** *(또는 `587`)* / **`STARTTLS`** | `2525` | **STARTTLS 필수** (평문 인증 차단됨) |
| | **인증 방식** | **일반 비밀번호 / SMTP 인증 사용** | - | 받는 메일 서버와 동일한 계정/비밀번호 사용 |

> [!IMPORTANT]
> **외부 네트워크(사내망/재택 등)에서 `25`번 포트로 발송이 안 되는 경우**  
> 많은 통신사(ISP)와 기업 방화벽이 스팸 차단을 위해 클라이언트 PC의 외부 `25`번 포트 접속을 차단합니다. 이 경우 서버 관리자가 **`587 → 2525`** 포트 포워딩을 추가로 열어두고, 클라이언트 보내는 메일 포트에 **`587`** (`STARTTLS`)을 입력하여 사용하십시오.

## 2. 클라이언트별 설정 방법

### 2.1 Microsoft Outlook (Windows - 클래식 Outlook)

1. Outlook 실행 ➔ 상단 메뉴 **파일** ➔ **계정 추가** 클릭
2. 이메일 주소 입력 후 **고급 옵션** 펼치기 ➔ **수동으로 내 계정 설정** 체크 ➔ **연결**
3. 계정 유형 선택 화면에서 **IMAP** 클릭
4. **IMAP 계정 설정** 입력:
   - **받는 메일**:
     - 서버: `mail.yourdomain.com`
     - 포트: `993`
     - 암호화 방법: **`SSL/TLS`**
   - **보내는 메일**:
     - 서버: `mail.yourdomain.com`
     - 포트: `25` *(또는 `587`)*
     - 암호화 방법: **`STARTTLS`**
   - *SPA(보안 암호 인증)를 사용한 로그온 필요*: **체크 해제**
5. **다음** ➔ 비밀번호 입력 ➔ **연결**
6. *(발송 인증 확인)* **파일 ➔ 계정 설정 ➔ 계정 설정 ➔ 해당 계정 더블 클릭 ➔ 기타 설정 ➔ 보내는 메일 서버** 탭에서 아래 항목 확인:
   - **보내는 메일 서버(SMTP) 인증 필요** 체크
   - **받는 메일 서버와 동일한 설정 사용** 선택

### 2.2 Microsoft Outlook (Windows - New Outlook)

1. 우측 상단 **설정(톱니바퀴)** ➔ **계정** ➔ **계정 추가** 클릭
2. 이메일 주소 입력 후 **계속** ➔ 공급자 선택에서 **IMAP** 선택
3. **자세히 보기** 토글을 켜고 아래 항목 입력:
   - **IMAP 받는 메일 서버**: `mail.yourdomain.com` / 포트: `993` / 보안 연결 유형: **`SSL/TLS`**
   - **SMTP 보내는 메일 서버**: `mail.yourdomain.com` / 포트: `25` *(또는 `587`)* / 보안 연결 유형: **`STARTTLS`**
   - **SMTP 사용자 이름 / 비밀번호**: 이메일 주소 및 비밀번호 동일하게 입력
4. **계속** 클릭하여 연동 완료

---

### 2.3 Mozilla Thunderbird (Windows / macOS / Linux)

1. Thunderbird 실행 ➔ **계정 설정** ➔ **계정 작업** ➔ **메일 계정 추가**
2. 이름, 이메일 주소(`user@yourdomain.com`), 비밀번호 입력 후 **수동 설정** 클릭
3. **서버 설정** 입력:
   - **받는 서버**:
     - 프로토콜: `IMAP`
     - 호스트 이름: `mail.yourdomain.com`
     - 포트: `993`
     - 연결 보안: **`SSL/TLS`**
     - 인증 방식: **`일반 비밀번호`**
   - **보내는 서버**:
     - 호스트 이름: `mail.yourdomain.com`
     - 포트: `25` *(또는 `587`)*
     - 연결 보안: **`STARTTLS`**
     - 인증 방식: **`일반 비밀번호`**
   - **사용자 이름**: 받는 서버 / 보내는 서버 모두 전체 이메일 주소(`user@yourdomain.com`) 입력
4. **다시 테스트** ➔ **완료** 클릭

---

### 2.4 Apple Mail (macOS / iOS)

1. **설정(또는 시스템 설정) ➔ Mail ➔ 계정 ➔ 계정 추가 ➔ 다른 Mail 계정** 선택
2. 이름, 이메일 주소(`user@yourdomain.com`), 비밀번호 입력 후 **로그인**
3. 수동 설정 화면이 나타나면 **IMAP** 선택 후 입력:
   - **받는 메일 서버**: 호스트 이름 `mail.yourdomain.com`, 사용자 이름 `user@yourdomain.com`, 비밀번호 입력
   - **보내는 메일 서버**: 호스트 이름 `mail.yourdomain.com`, 사용자 이름 `user@yourdomain.com`, 비밀번호 입력
4. 저장 후 계정 상세 설정에서 포트 및 SSL 확인:
   - **IMAP**: 포트 `993`, SSL 사용 **켬**
   - **SMTP**: 포트 `25` *(또는 `587`)*, SSL 사용(`STARTTLS`) **켬**, 인증 **비밀번호**

## 3. 서버 관리자 점검 사항 및 트러블슈팅

### 3.1 `587` (Submission) 포트 추가 포워딩 (권장)
클라이언트 PC에서 `25`번 포트가 차단된 경우를 대비해 Linux 서버에서 `587 → 2525` 포워딩을 함께 구성할 수 있습니다:
```bash
sudo iptables -t nat -A PREROUTING -p tcp --dport 587 -j REDIRECT --to-port 2525
```
방화벽(UFW/firewalld/클라우드 보안 그룹)에서도 `587/tcp`, `993/tcp`, `143/tcp` 인바운드를 허용해 주십시오.

### 3.2 자주 발생하는 오류 및 해결

| 증상 / 오류 메시지 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| `530 5.7.0 Must issue a STARTTLS command first` | 보내는 메일(SMTP) 암호화가 **없음(평문)**으로 설정됨 | 클라이언트 SMTP 암호화 방식을 **`STARTTLS`**로 변경 |
| `no shared cipher` (`lemail-api` 로그) | API 서버가 SMTP TLS 인증서를 로드하지 못함 | `.env`에 `MAIL_TLS_CERT` / `MAIL_TLS_KEY`(또는 `IMAP_TLS_*`) 경로가 올바르게 설정되어 있는지 확인 후 `pm2 restart lemail-api` 실행 (`[SMTP TLS] Loaded TLS certificate` 로그 확인) |
| 받는 메일(`993`) 연결 시간 초과 | 방화벽 또는 포트 포워딩(`993 → 1993`) 누락 | 서버 방화벽 `993/tcp` 개방 및 Nginx Stream / iptables 포워딩 설정 확인 |
| 보내는 메일(`25`) 연결 시간 초과 | 사내 방화벽 또는 ISP에서 `25`번 아웃바운드 차단 | 서버에 `587 → 2525` 포워딩 추가 후 클라이언트 SMTP 포트를 `587`로 변경 |
| 보안 인증서 경고 팝업 | 사설(자체 서명) 인증서 사용 또는 도메인 불일치 | 접속 도메인(`mail.yourdomain.com`)과 일치하는 공인 SSL 인증서(Let's Encrypt 등) 적용 |
